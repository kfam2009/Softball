Stream Deck - Softball NDI Scorebug

Usar en Stream Deck:

1. Elegir la accion: Sistema > Abrir.
2. En "App / Archivo", seleccionar uno de estos archivos .vbs.
3. El panel/NDI debe estar levantado (ARRANCAR SOFTBALL.cmd).

Scorebug:  SCOREBUG_IN.vbs  SCOREBUG_OUT.vbs
Conteo:    BALL_PLUS.vbs (4ta bola = base por bolas)  STRIKE_PLUS.vbs (3er strike = out)  FOUL.vbs  COUNT_RESET.vbs  WALK.vbs
Outs:      OUT_PLUS.vbs (3er out = cambio de lado)  OUT_MINUS.vbs  OUTS_CLEAR.vbs  CHANGE_SIDE.vbs
Carreras:  RUN_PLUS.vbs (equipo que batea)  AWAY_PLUS.vbs  AWAY_MINUS.vbs  HOME_PLUS.vbs  HOME_MINUS.vbs
Hits/Err:  HIT_PLUS.vbs (equipo que batea)  ERROR_PLUS.vbs (equipo que defiende)
Bases:     BASE_1.vbs  BASE_2.vbs  BASE_3.vbs  BASES_CLEAR.vbs
Publicid.: AD_IN.vbs  AD_NEXT.vbs  AD_OUT.vbs  ZOCALO_IN.vbs  ZOCALO_NEXT.vbs  ZOCALO_OUT.vbs
Entrada:   INNING_PLUS.vbs  INNING_MINUS.vbs  HALF_TOGGLE.vbs

Iconos en icons\ (los nuevos de conteo se pueden crear con create-icons.ps1 o usar texto en Stream Deck).
No usar el plugin de vMix para estas acciones.
